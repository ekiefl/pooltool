# Sound effects

These clips were taken from [tailuge/billiards](https://github.com/tailuge/billiards) (`dist/sounds/`), which is licensed under the GNU General Public License v3. pooltool is Apache-2.0, so these files must be replaced with compatibly-licensed clips before this feature ships.

| File | Played on |
| --- | --- |
| `cue.ogg` | cue stick striking the cue ball |
| `ballcollision.ogg` | ball-ball collisions |
| `cushion.ogg` | ball-cushion collisions and balls landing on the table |
| `pot.ogg` | a ball dropping into a pocket |
